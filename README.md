# 🐍 بوت Python الذكي

بوت تيليجرام متخصص في Python يعمل بـ Groq API.

---

## 📁 الملفات

| الملف | الوظيفة |
|---|---|
| `bot.py` | الكود الرئيسي |
| `keyboards.py` | كل أزرار البوت |
| `railway.toml` | إعدادات الاستضافة |
| `requirements.txt` | المكتبات |

---

## 🚀 الرفع على Railway

1. ارفع المجلد كـ GitHub repo
2. ادخل [railway.com](https://railway.com) → New Project → Deploy from GitHub
3. أضف متغيرات البيئة:
   - `BOT_TOKEN` — توكن البوت من @BotFather
   - `GROQ_API_KEY` — مفتاح Groq من console.groq.com
   - `ADMINS` — رقم ID الأدمن (مثال: `123456789`)
4. Deploy ✅

---

## 🤖 استخدام /dew في المجموعة

> يشترط أن يكون البوت **أدمن** في المجموعة

| الاستخدام | النتيجة |
|---|---|
| `/dew كيف أعمل decorator؟` | يجيب على السؤال |
| رد على رسالة نص + `/dew` | يحلل النص |
| رد على صورة كود + `/dew` | يشرح المشكلة |
| رد على ملف .py + `/dew سؤال` | يقرأ الملف ويجيب |

## 📊 الإحصائيات

أمر `/stats` أو زر **إحصائيات كاملة** في لوحة الأدمن يعرض:
- عدد المستخدمين
- إجمالي الرسائل
- عدد الصور المحللة
- عدد الملفات المعالجة
- عدد استخدامات /dew
- تاريخ بدء التشغيل

## ⚙️ الأوامر

### للجميع
- `/start` — البداية + القائمة
- `/menu` — القائمة الرئيسية
- `/clear` — مسح الذاكرة
- `/stats` — الإحصائيات
- `/help` — المساعدة
- `/dew` — السؤال عبر المجموعة

### للأدمن فقط
- `/admin` — لوحة الأدمن
- `/broadcast رسالتك` — بث لجميع المستخدمين
